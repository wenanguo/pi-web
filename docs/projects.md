# 项目面板

右侧面板的第一个标签页是**项目**：你有哪些项目、每个项目的里程碑、里程碑下的任务，
都在这里看和改。

![项目面板](../test-results/projects-panel.png)

## 项目从哪来

**项目 = 你跑过会话的目录**（和左侧栏的项目分组是同一套）。没有会话的项目不会出现在
这里 —— 一个目录里跑过一次会话，它就成了一个项目，按最近活动排序。

项目名用左侧栏项目菜单里改过的名字；没改过就用文件夹名。

## 里程碑与任务

一个项目下面是一串**里程碑**，每个里程碑下面是一串**任务**。

| 字段 | 说明 |
| --- | --- |
| 里程碑 | 标题、状态（未开始 / 进行中 / 已完成 / 受阻）、截止日期、任务列表 |
| 任务 | 标题、状态（待办 / 进行中 / 已完成 / 受阻）、负责人、截止日期、优先级（高 / 中 / 低） |

面板顶部是项目切换（每个项目角上写着完成了几条任务），下面是当前项目的总进度条和
里程碑卡片。点里程碑左边的箭头可以折叠它。

**改完自动保存**，面板底部会显示「保存中 / 已保存 / 保存失败」。保存失败时错误原因
留在底部，刷新页面不会丢已经写进去的内容。

## 和对话连起来

任务行上有一个**对话气泡**按钮：点了就把这个任务带进左边的输入框，光标落在后面，
你可以接着写你的要求再发送。带过去的是这样一段：

```
任务: 人格 + 能力扩展机制
项目: pi-web (D:\project\pi-web)
里程碑: 定制 agent 体系
状态: 已完成 | 优先级: 高

```

模型看到的就是「哪个项目的哪个里程碑下的哪个任务，现在什么状态」，后面跟着你的话。

会话目录和任务所属项目不是同一个时，会话目录也会写进去 —— 模型是在那个目录里干活的，
任务在别处，得说清楚。

气泡右边的 **▾** 是**常用指令**：扩展这个任务 / 总结这个任务 / 拆解这个任务。选一个，
输入框里就是「任务上下文 + 那句指令」，你还能改完再发。

## 数据存在哪

`~/.pi/agent/pi-web-projects.json`（和 pi 的文件放在一起），按项目键索引：

```json
{
  "version": 1,
  "revision": 7,
  "projects": {
    "d:\\project\\pi-web": {
      "projectKey": "d:\\project\\pi-web",
      "milestones": [
        {
          "id": "m-3f9a2c1d",
          "title": "定制 agent 体系",
          "status": "in-progress",
          "due": "2026-11-30",
          "tasks": [
            { "id": "t-8b2c1d0e", "title": "人格 + 能力扩展机制", "status": "done", "priority": "high" }
          ]
        }
      ]
    }
  }
}
```

写入是加锁的（别的进程也在用同一个文件时不会互相覆盖）、原子的（先写临时文件再改名），
文件坏了会被挪到一边备份，不会被覆盖掉。

**项目目录里一个字节都不会写** —— 计划和代码分开，代码归 git 管，计划归这个文件管。

## 和 agent 一起用

这个面板只管给人看。agent 要读写计划，走 API：

```bash
# 读某个项目的计划
curl http://127.0.0.1:30141/api/projects

# 写某个项目的计划（整份替换，其它项目不动）
curl -X PUT http://127.0.0.1:30141/api/projects \
  -H "Content-Type: application/json" \
  -d '{"projectKey":"d:\\project\\pi-web","roadmap":{"projectKey":"d:\\project\\pi-web","milestones":[]}}'
```

一个定制 agent 想要「读当前项目的里程碑并汇报进度」，可以直接调这个 API，或者让
agent 用 `read` 读 `~/.pi/agent/pi-web-projects.json`（路径在 agent 的提示词里给出来）。
